## 关于这个仓库

这是一个**个人叙事型仓库**，不是技术项目。

互联网上看到的求职故事大多是成功者的案例，而现实是：绝大多数普通背景的应届生，都在反复试错、反复碰壁、反复怀疑自己。我想把这些不"光鲜"的经历原样记录下来——既是给自己的复盘，也可能给处境相似的人一点参考。

> 记录原则：真实 > 体面。
