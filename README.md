# finding-my-way
记录我的成长、求职、职业探索与未来目标。

## 过去到现在：经历与想法
- 从最初对技术的兴趣出发，我持续学习编程、项目实践和问题解决方法。
- 在学习和尝试中，我逐渐意识到：比“会写代码”更重要的是“能持续交付价值”。
- 过去的经历让我明白，职业发展不是线性前进，而是在试错中不断校准方向。

## 找不到工作的焦虑
- 求职阶段最明显的感受是焦虑：投递很多、反馈很少，容易怀疑自己。
- 焦虑的根源往往不是能力本身，而是信息不对称、岗位匹配度和表达方式不足。
- 我正在尝试把焦虑转化为行动：复盘项目、优化简历、强化面试表达、保持稳定节奏。

## 未来目标与经验梳理
### 目标岗位画像
- 以软件开发/工程岗位为主，重视技术成长空间、协作氛围和真实业务价值。
- 希望在团队中承担从需求理解到落地交付的完整责任，而不只是执行单点任务。

### 已有经验沉淀
- **技术能力**：具备基础开发能力，能够独立完成小型功能开发与问题排查。
- **项目意识**：开始关注需求背景、交付质量、可维护性和沟通效率。
- **成长方法**：通过记录、复盘和阶段性目标，持续改进学习与求职策略。

### 下一步行动
- 持续完善作品与项目说明，用结果而不是口号展示能力。
- 针对目标岗位补齐薄弱项（如系统设计、工程化、业务理解）。
- 维持长期投入，在不确定中保持清晰方向与执行力。
