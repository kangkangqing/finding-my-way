# 职业方向探索

> 记录我从"以为自己想做什么"到"知道自己能做什么"的方向校准过程。

## 1. 过去我期望的职业

毕业前，我考虑过这些方向，但每条路都碰到了现实的墙：

| 方向 | 为什么没走通 |
|------|-------------|
| Java 开发 | 梦想中的方向，但**学历门槛太高**，根本进不去 |
| 测试 | 时间来不及了，也不知道该从哪儿学起 |
| 运维 | 只了解桌面运维这一种，认知有限 |
| AI Agent 开发 | 本质上还是开发岗，**学历要求高**，同样进不去 |

结论：**学历这道墙，把我挡在了大部分主流开发岗之外。**

## 2. 现在我期望的职业：IT 工程师（制造业）

经过实习和求职的反复尝试，我找到了一个和自身背景比较匹配的方向——**工厂或有实际产出产品的公司里的 IT 工程师**。

**工作内容**

- ERP、MES 等系统的日常维护
- 可附带桌面运维

**我为什么选这个方向**

| 优点 | 说明 |
|------|------|
| ✅ 学历门槛低 | 三本学历能敲门 |
| ✅ 有技术含量 | 不是纯杂活，需要持续学习 |
| ✅ 吃经验和业务 | 年纪在这里反而是优势，越老越值钱 |
| ✅ 不卷、不 996 | 工作节奏和互联网公司完全不同 |

---

> 一句话总结：这是**结合我的学历、性格和兴趣现状**，我认为对自己来说最合适的方向。
